<objective>
Consolidate the dual cache-path substitution pipeline into a single authoritative pass
in utils.py. Remove the module-level replace_cache_path() calls from the TEMPLATES dict
in all_templates.py so templates are stored raw. Define CACHE_PATH_SENTINEL once.
Convert three f-string backref re.sub calls to lambda repl.

Purpose: Two independent substitution passes currently compose correctly only by
accident. The all_templates.py pass uses service names; utils.py overwrites with the
domain-qualified unique_id. Removing the first pass makes utils.py the sole rewrite
site and eliminates the hidden ordering dependency. The lambda repl change makes
back-reference semantics explicit and future-proof. CACHE_PATH_SENTINEL prevents
sentinel drift across 18 template files.

Output:
- nginx_set_conf/templates/all_templates.py — CACHE_PATH_SENTINEL constant added;
  TEMPLATES dict stores raw templates; get_config_template() simplified to dict lookup
- nginx_set_conf/utils.py — first re.sub broadened to match /tmp; 3x lambda repl
- tests/test_templates.py — golden-output snapshot class (committed BEFORE any refactor)
  + raw-sentinel assertion test
</objective>

| Template string → regex substitution pipeline | Raw /tmp sentinel in template must be rewritten by utils.py before the content reaches the filesystem; no raw sentinel must escape to nginx config |
| utils.py execute_commands → /etc/nginx/conf.d/{domain}.conf | The final written content must contain a domain-qualified cache path, not /tmp or a service-name-only path |

| T-02-01-02 | Tampering | keys_zone f-string backref with special chars in unique_id | mitigate | COR-05 fix: lambda repl replaces f"\\1..." form; m.group(1) is explicit and immune to digit-prefix or backslash in unique_id |
