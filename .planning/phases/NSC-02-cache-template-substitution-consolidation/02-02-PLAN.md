<objective>
Make redirect_domain required for the redirect and redirect_ssl templates by adding a
sentinel-leak guard to validate_all_inputs() in validators.py. When config_template is
"redirect" or "redirect_ssl" and redirect_domain is empty, a ValidationError is raised
before execute_commands writes any file — preventing the literal "target.domain.de"
sentinel from appearing in nginx log file paths.

Purpose: nginx silently accepts "target.domain.de" as a log path fragment, writing to
/var/log/nginx/target.domain.de-access.log when redirect_domain is omitted. This is a
correctness bug (COR-MED-2): the sentinel leaks into real log paths. Adding the guard
to validate_all_inputs() is consistent with the existing validation pattern and ensures
the error is reported before any filesystem side-effect.

  required check (4-line addition inside the function body)
