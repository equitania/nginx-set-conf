| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Information Disclosure | nginx_set_conf.log tracked in git | mitigate | git rm --cached removes it from index; *.log rule in .gitignore prevents future re-tracking |
| T-03-02-02 | Tampering | Accidental deletion of wrong egg-info directory | mitigate | Task 1 explicitly confirms git ls-files returns empty before rm -rf; path scoped to the project working directory |
| T-03-02-03 | Information Disclosure | build/dist artefacts potentially tracked (contain compiled code) | accept | Planning confirms both are already gitignored; Task 2 Step 3 verifies no tracked files exist in either directory |
| T-03-02-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan |

Security posture note: Untracking nginx_set_conf.log eliminates the risk that future log content
(which may contain domain names, IP addresses, or operator inputs from --dry_run invocations)
leaks into git history. The sentinel-leak and log-path guards from Phase 2 are unaffected —
they control what is written to nginx config files, not to the log file.
