<objective>
Fix `validate_target_path` in `validators.py` so that whitespace-padded and
Unicode-whitespace-prefixed paths are stripped before the traversal check, and
so the check uses the segment-split `_reject_path_traversal` helper (already
used by every other path validator in the module) instead of the raw `".." in`
substring test.

Purpose: A raw substring check on an un-stripped string has subtle failure modes
with Unicode whitespace (NBSP, tab characters) that interact poorly with
`os.path.realpath`. Calling `_reject_path_traversal` after `.strip()` is the
established pattern used by `validate_cert_name`, `validate_cert_key`, and
`validate_auth_file` — SEC-01 closes the consistency gap.

  whitespace-variant test methods
