<objective>
Convert `retrieve_valid_input` in `utils.py` from a recursive function to an
iterative loop, add a module-level `_MAX_INPUT_LENGTH = 4096` constant that caps
input to prevent memory exhaustion on piped stdin, and add an `EOFError` handler
that exits cleanly instead of crashing with a traceback.

Purpose: The current recursive implementation hits Python's default recursion
limit (1000) after 1000 consecutive empty `<Enter>` presses, producing an
unhandled `RecursionError`. A piped stdin with no input immediately raises an
unhandled `EOFError`. Both are observable crashes in the CLI. The fix is a
straightforward `while True:` conversion — the only recursive input loop in the
codebase.

  `retrieve_valid_input` with `EOFError` handler (10-line change)
