<objective>
Fix `backup_configuration` in `config_verification.py` by:
1. Adding an `os.path.islink` guard that returns False (and logs an error) when
   the source directory `/etc/nginx/nginxconfig.io` is itself a symlink.
2. Making `symlinks=False` explicit on the `shutil.copytree` call (it is already
   the default but making it explicit is correct for documentation and
   future-proofing).
3. Adding `nginx_conf_path` and `nginxconfig_dir` parameters with defaults, so the
   function is testable without patching builtins — mirroring how
   `setup_default_server` accepts `target_path`, `ssl_dir`, etc.

Purpose: An attacker or operator mistake that replaces `/etc/nginx/nginxconfig.io`
with a symlink to `/root` or `/etc/shadow` would cause `shutil.copytree` to follow
it and read sensitive files into the backup archive. The `islink` guard on the
source directory (threat a) combined with explicit `symlinks=False` (threat b)
closes both attack vectors.

Output:
- `nginx_set_conf/config_verification.py` — `backup_configuration` hardened (6-line change)
- `tests/test_backup.py` — new file, class `TestBackupConfiguration`
</objective>
