           > **WARNING — Firewall action required:** HTTP/3 uses UDP/443 in addition to TCP/443. Without this, QUIC connections are silently dropped and browsers fall back to HTTP/2 — the Alt-Svc header is effectively dead.

       (5) Opt-in design — the flag must be set explicitly; no existing operator sees any change without adding --enable_http3 or enable_http3: true to YAML.

    3. USAGE subsection (### Usage):

         nginx-set-conf --config_template odoo_ssl --ip 1.2.3.4 --domain erp.example.com \

       YAML example (inline code block):
         enable_http3: true
       Note: both CLI flag and YAML key produce identical output.

       ### Added

       - **[ADD]** **HTTP/3 / QUIC opt-in support** — new `--enable_http3` flag (and YAML key `enable_http3: true`) adds QUIC + HTTP/3 listen directives to 12 browser-facing SSL templates: `odoo_ssl`, `flowise`, `n8n`, `nextcloud`, `guacamole`, `kasm`, `pgadmin`, `portainer`, `pwa`, `code_server`, `supabase`, `qdrant` (REST port only).
