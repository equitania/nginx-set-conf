    get_nginx_version():
    - Runs subprocess.run(["nginx", "-v"], capture_output=True, text=True).
    - Parses stderr with regex r"nginx/(\d+)\.(\d+)\.(\d+)".
    - Returns (int, int, int) tuple or None on FileNotFoundError or no match.
    - Never raises; always returns tuple or None.

    _quic_reuseport_already_claimed(conf_dir, ip, port=443):
    - CRITICAL FIX: The regex must match BOTH IP-bound and wildcard reuseport forms on the target port. The default_ssl_reject QUIC catch-all (05-03) emits `listen 443 quic default_server reuseport;` — a wildcard form with NO ip prefix. A regex that requires an IP prefix (`listen\s+{ip}:{port}\s+quic\s+reuseport`) will miss this and cause every subsequent vhost to also emit reuseport, resulting in nginx reload failure with duplicate reuseport on UDP/443.
    - Correct regex pattern: `rf"listen\s+(?:{re.escape(ip)}:)?{port}\s+quic\b.*\breuseport"` — the `(?:{re.escape(ip)}:)?` group makes the IP prefix optional, matching both `listen 1.2.3.4:443 quic reuseport;` and `listen 443 quic default_server reuseport;` on the same port.
    - Returns True if found, False if not found or OSError/PermissionError.
    - Does NOT raise on filesystem errors — gracefully returns False (safe default: emit reuseport when unsure).
