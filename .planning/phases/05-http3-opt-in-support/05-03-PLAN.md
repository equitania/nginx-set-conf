<objective>
Complete the security posture of the HTTP/3 feature: (1) add the nginx version gate that blocks emission on too-old nginx, (2) extend default_ssl_reject with a QUIC catch-all server block that mirrors the v1.10.0 lesson (SNI-fallback risk exists for QUIC exactly as it did for TCP/443 wildcard listens).

Purpose: Without the version gate, operators on nginx 1.24 would get nginx -t failures with the opaque "[emerg] unknown directive quic". Without the QUIC catch-all in default_ssl_reject, an unrecognized SNI on UDP/443 would fall back to the first-loaded QUIC server block, potentially exposing the wrong certificate — the HTTP/3 form of the v1.10.0 incident.

Output: Version gate in execute_commands (before file write), QUIC catch-all block in default_ssl_reject.py TEMPLATE, TestHttp3DefaultCatchAll and TestNginxVersionGate in test_templates.py.
</objective>
